# 3. Required C Standard & System Header Libraries
stdio.h      - Standard Input/Output library (printf, standard console text output)
stdlib.h     - Standard General Utilities library (system("cls") for clearing screen)
conio.h      - Console Input/Output header (_kbhit() for non-blocking key check, _getch() for instant key capture)
windows.h    - Windows API header (GetStdHandle, SetConsoleCursorPosition, SetConsoleCursorInfo, Sleep)
stdbool.h    - Boolean data type support (bool, true, false)
